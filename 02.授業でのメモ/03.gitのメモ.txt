---------------------------------------------------------------------------------------------------
[ブランチ操作]
# 現在のブランチを確認
git branch

# 新しいブランチを作成して移動
git switch -c [ブランチ名]

# 新しいブランチを作成するが移動はしない
git switch [ブランチ名]

# ブランチ間移動
git switch [ブランチ名]

[git switchのオプション]
-c : 新しいブランチを作成して移動

[git branchのオプション]
-a : すべてのブランチを表示
-r : リモートブランチを表示
---------------------------------------------------------------------------------------------------
[コミット操作]
# git add ./ + git commit -m "hogehoge"と同じ
git commit -am "hogehoge"

# 直前のコミットを修正
git commit --amend -m "正しいメッセージ"

# 変更を追加して、直前のコミットにまとめたい。でもメッセージはそのままでいい
git commit --amend --no-edit

[git commitのオプション]
-am :
--amend :
--no-edit :
